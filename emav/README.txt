EMAV macOS Installation Instructions
==================================

1. Double-click to open this zip file.
2. Inside, you will see a package installer named "EMAV_App.pkg".

IMPORTANT SECURITY NOTICE:
Because this application is not signed by Apple's developer certificate, macOS Gatekeeper will block it if you simply double-click the package. 

To bypass this and install EMAV:
1. Hold the "Control" key and click (or right-click) on "EMAV_App.pkg".
2. Choose "Open" from the pop-up menu.
3. A warning box will appear saying the developer cannot be verified. Click the "Open" button in that dialog.
4. Follow the installer steps. 

EMAV will be installed directly into your Applications/BTNRH folder.

Data Files:
When you launch EMAV, it is pre-configured to look for its configuration file (emav.ini) and save your data files directly into your Documents folder!
